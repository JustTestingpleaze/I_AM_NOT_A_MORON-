Overview

Heyaaa, I'm Touch_Grass. I mostly spend my free time messing around with code, 3D art, animation, and VFX. I've been using Python and Lua on and off for about a year, and I've spent the last year doing the same with Blender for 3D modeling, animation, and VFX.
